Migrate legacy project MEMORY.md records into the Memory V1 metadata carrier. This is a controlled, fail-closed migration; it never writes retracted.md.

Only canonical projects/<project>/MEMORY.md is supported. Existing valid metadata is preserved, partial metadata is reported and skipped, records whose metadata raises a diagnostic are skipped and reported, malformed metadata and duplicate IDs abort the whole operation. The result reports token budget, truncation and complete-visible record counts; if the added metadata would shrink what fits in the memory budget the migration is refused, so trim MEMORY.md first. dry_run performs the same computation without writing.
