## 2. 建设方向（5 个）

### P0-1：执行反馈闭环（L2 修复 + 统一超时）

| 项 | 内容 |
|----|------|
| 当前缺口 | bash exit≠0 不发 error ToolCall；本地工具无统一超时 |
| 建设价值 | 消除最高频工具的反馈失真；Immune 观测覆盖全工具 |
| 前置依赖 | Immune V1 冻结边界确认（L2 属 post-V1 独立任务） |
| 实施复杂度 | **低-中**（L2 ~20 行 + 测试；统一超时 ~50 行 + 各工具适配） |
| 预期收益 | 错误识别率大幅提升；bash 成功率统计真实化 |
| 验收标准 | exit≠0 产生 error ToolCall + 7 字段；read/edit/write 超时可配且默认合理 |
| 优先级 | **P0**（影响面最广，改动最小） |

### P0-2：Memory 语义检索增强

| 项 | 内容 |
|----|------|
| 当前缺口 | 纯 BM25，无语义/向量回退 |
| 建设价值 | 检索质量决定规划上限；同义改写/隐式关联是常见查询模式 |
| 前置依赖 | embedding 模型选型；FTS 索引扩展或旁路向量索引 |
| 实施复杂度 | **中-高**（embedding 管道 + 索引 + 检索融合 + 预算控制） |
| 预期收益 | 记忆检索准确率提升；经验复用有效性提升 |
| 验收标准 | MEM-03/04/05 测试集得分提升；BM25+语义混合检索可 A/B |
| 优先级 | **P0**（记忆是长期能力的地基） |

### P1-1：任务编排代码保障

| 项 | 内容 |
|----|------|
| 当前缺口 | 任务树完全依赖模型调 task 工具；DB 空时恢复链路空转 |
| 建设价值 | 长任务可靠性；崩溃恢复不丢状态 |
| 前置依赖 | task 状态机已有（schema/registry）；需补自动登记+依赖边 |
| 实施复杂度 | **中**（自动登记钩子 + sibling 依赖边 + DAG 拓扑排序） |
| 预期收益 | 长任务状态保持率提升；恢复精确度提升 |
| 验收标准 | LONG-01/04 测试集得分提升；DB 空场景有兜底 |
| 优先级 | **P1** |

### P1-2：失败恢复加固（Goal fail-open + orDie 区分）

| 项 | 内容 |
|----|------|
| 当前缺口 | Goal 判官异常直接放行；write/edit orDie 无 Recoverable 区分 |
| 建设价值 | 消除"未完成被放行"和"可重试错误被当 defect"两类失真 |
| 前置依赖 | Immune V1 RecoverableError 分类已有 |
| 实施复杂度 | **低-中**（goal 二次确认 + write/edit 错误分类 ~30 行） |
| 预期收益 | 故障恢复成功率提升 |
| 验收标准 | FAULT-01/04 测试集得分提升 |
| 优先级 | **P1** |

### P2-1：记忆冲突/过期治理

| 项 | 内容 |
|----|------|
| 当前缺口 | expectedRevisions 空转；无 TTL/衰减；事实 vs 推断无区分 |
| 建设价值 | 长期记忆质量；防止错误信息永久存活 |
| 前置依赖 | immune-memory confidence schema 已有（未接线） |
| 实施复杂度 | **中**（接线 confidence + TTL 策略 + validator 启用） |
| 预期收益 | 记忆过期处理正确率提升（XSESS-04） |
| 验收标准 | 冲突场景正确覆盖；过期记忆有标注 |
| 优先级 | **P2** |

## 3. 优先级排序与理由

```
P0-1 执行反馈闭环（L2+超时）
  ↓ 影响面最广、改动最小、立即可做
P0-2 Memory 语义检索
  ↓ 记忆是长期能力地基，决定规划上限
P1-1 任务编排代码保障
  ↓ 长任务可靠性，依赖 P0-1 的反馈真实性
P1-2 失败恢复加固
  ↓ 依赖 Immune V1 的 RecoverableError（已有）
P2-1 记忆冲突/过期治理
  ↓ 依赖 P0-2 的检索增强（先能搜到，再治理质量）
```

**建议实施顺序**：P0-1 → P0-2 → P1-1 → P1-2 → P2-1

每个方向实施前须：
1. 提交变更清单 + 实施方案
2. 取得项目负责人批准
3. 按 E 框架跑基准对比（固定模型、固定环境）

| 大规模 prompt.ts 重构 | 单点但稳定；重构风险 > 收益，待有测试网兜底后再动 |
